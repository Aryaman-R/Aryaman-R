### 🛠️ Currently building

**[Sentient Assistant](https://github.com/Aryaman-R/SentientAssistant)** — a personal AI assistant that runs on one always-on device (a Raspberry Pi works great) and is reachable from every screen in the house. Voice-first when you want it, keyboard-first when you don't. Plays your Spotify, syncs your Google Tasks and Calendar bidirectionally, runs tools through Composio's MCP catalogue, and pipes through any LLM provider you give it a key for. One-line installer, in-UI setup wizard, no cloud account required.
